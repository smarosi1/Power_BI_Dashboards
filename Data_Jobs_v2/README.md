# Data Jobs Dashboard v2 w/ Power BI

![Dashboard Snapshot](/Images/DJDB2_Screenshot.png)

## Introduction

This dashboard uses a 2024 dataset of data science job postings to display useful metrics to data science job seekers. Using this dashboard, they can explore lots of information about the skills required and salaries offered for data jobs. They can also analyze each job title individually to see how they compare with others. This project offers a streamlined, single-page interface to quickly explore crucial market trends.

## Skills Showcased
- **Dashboard Design:** Crafting an intuitive and visually appealing report layout.
- **Power Query ETL:** Performing data cleansing, shaping, and transformation.
- **Data Modeling:** Building efficient data models with relationships (Star Schema principles).
- **DAX Fundamentals:** Creating calculations and aggregations to derive key insights.


## Dashboard Overview

This second iteration consolidates the dashboard into a **single, focused page**, designed to give job seekers the most critical market insights at their fingertips.

![Dashboard Snapshot](/Images/DJDB2_Screenshot.png)

This page acts asd your concise mission control for the data job market. It showcases key performance indicators (KPIs) like **Job Count, Skills Per Job, Median Yearly Salary, and Median Hourly Salary**. You can also quickly see **Skill Popularity** (by job percent or count) and compare **Salaries across different Job Titles**, all designed for an efficient overview.


## Conclusion

This updated dashboard (Version 2.0) showcases Power BI's ability to transform extensive job posting data into a powerful, streamlined tool for career analysis. It empowers job seekers by allowing them to filter and explore essential market insights efficiently on a single page, helping them make informed decision about their next career move.
